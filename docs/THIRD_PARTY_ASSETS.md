# Third-party assets registry

This file tracks external visual assets used in DASMLAB Home and the rights associated with them.

## Policy

- Only add assets with licenses that allow website/commercial usage.
- Track source URL, license type, attribution text, and placement path.
- Do not merge assets with unknown origin or unclear permissions.

## Registry template

| Asset ID | Source URL | License | Attribution required | Used in file/path | Notes |
|----------|------------|---------|----------------------|-------------------|-------|
| example-stock-001 | https://example.com/image | Unsplash License | No | `public/media/hero/example.webp` | Replace with real entry |

## Approval checklist

- License reviewed
- Attribution text prepared (if required)
- File optimized (WebP/AVIF where possible)
- Added to this registry before merge
